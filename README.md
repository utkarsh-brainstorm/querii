# Querii

Querii is a lightning-fast, lightweight desktop application designed for local data manipulation and SQL analysis. It bridges the gap between raw CSV/Excel spreadsheets and powerful relational database querying without the overhead of setting up a local database server or uploading data to the cloud.

The application leverages **PyWebView** to present a modern, single-page web interface built with Vanilla JS, Tailwind CSS, and HTML5, all running against a lightweight, embedded Python backend powered by SQLite.

---

## 🏗 Architecture Overview

Querii is split into two primary components that communicate seamlessly via Inter-Process Communication (IPC):

### 1. The Python Backend (`main.py` & `api.py`)

- **Database Engine (`core/db.py`)**: Manages a persistent SQLite database stored locally.
- **Import/Export (`core/importer.py` & `core/exporter.py`)**: Fast parsing of Excel (`.xls`, `.xlsx`) and CSV files directly into SQL tables using optimized batched insertion. Handles PDF/CSV generation.
- **Dynamic Query Builder (`core/query_builder.py`)**: Translates visual filter rules (JSON) generated by the UI into sanitized SQL queries.
- **Pagination API**: Employs a robust chunking algorithm (`api.py`) to serve massive datasets to the frontend without choking the IPC bridge or freezing the GUI.

### 2. The Frontend (`web/app.js` & `web/index.html`)

- **Native WebViews**: Runs on WebKit2GTK (Linux), WKWebView (macOS), or Edge WebView2 (Windows).
- **Virtual DOM**: High-performance UI rendering that efficiently paints thousands of table cells using `DocumentFragment`.
- **Vanilla JS & Tailwind**: Zero complex build steps. No Webpack, no React. Just lightning-fast Vanilla JavaScript and Tailwind CSS utility classes.

## 🚀 Getting Started for Developers

### Prerequisites

You need **Python 3.8+** installed on your system. 

#### System Requirements (Linux)

On Linux systems, you will need GTK3 and WebKit2GTK bindings:

```bash
sudo apt-get install python3-gi python3-gi-cairo gir1.2-gtk-3.0 gir1.2-webkit2-4.1
```

### Installation

1. Clone the repository.
2. Install the Python dependencies:
   
   ```bash
   pip install -r requirements.txt
   ```
   
   *(Dependencies include `pywebview`, `openpyxl`, `xlrd`, `reportlab`)*

### Running the App

Run the application locally during development:

```bash
python main.py --debug
```

> **Note:** The `--debug` flag enables the WebView developer tools (Inspector) so you can debug the frontend JavaScript and CSS.

## 🛠 Building Executables (Release)

Querii is packaged into standalone binaries using `PyInstaller`. This removes the need for end-users to install Python or any dependencies.

### Local Build Command

To build a single-file executable for your current operating system, run:

```bash
pyinstaller --noconfirm --onefile --windowed --add-data "web:web" --name querii main.py
```

*Note: On macOS, omit `--windowed` to ensure a strict single-file binary output.*

The resulting binary will be located in the `dist/` directory.

### GitHub Actions (Automated Release)

This project is configured with a GitHub Actions workflow (`.github/workflows/release.yml`) that automatically cross-compiles Windows, macOS, and Linux binaries whenever a push is made to the `master` branch. The direct executables are attached directly to the GitHub Releases page.

## 🧠 Key Design Decisions

- **No Zipped Releases:** By utilizing `PyInstaller --onefile`, we ship raw executables for all platforms directly. The end-user double clicks the file, and the application instantly boots.
- **Hardware Acceleration Toggles:** On Linux, Wayland can occasionally cause WebKitGTK's hardware acceleration to freeze. `main.py` strictly forces software compositing (`WEBKIT_DISABLE_COMPOSITING_MODE=1`) to guarantee perfect stability across all Linux window managers.
- **No JS Frameworks:** The frontend strictly uses Vanilla JS to maintain a tiny memory footprint. UI components (like the Nested Filter Builder) manipulate the DOM directly.
