Querii v1.0

A generalised sheet-to-SQL querier. Fork of AttendanceProcessor.

Drop any XLS, XLSX, or CSV file. Querii auto-detects column types, creates a SQLite table, and lets you filter, group, and export using SQL — no configuration required.

How to use

  1. Import — Drop a file or click Browse. Querii shows you a Schema Preview: detected columns, inferred types, sample values. Adjust the header row number if needed, then click Import.
  2. Select table — Each imported file becomes its own SQLite table. Pick the active table from the dropdown in the Search panel.
  3. Filter visually — Click + Add to add filter rows. Fields are dynamically built from the table's actual columns.
  4. Write SQL — The SQL editor auto-fills from the filter builder, but you can write anything. Hit Ctrl+Enter to run.
  5. Schema panel — The Schema tab on the right shows all tables, their columns, types, and sample SQL snippets you can click to copy.
  6. Export — Any result set can be exported to CSV or PDF from the Results panel.
  7. Saved Reports — Save any SQL as a named shortcut for one-click re-running.
