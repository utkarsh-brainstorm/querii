Querii v2.0

⚡
Made by Heisenberg

"I built this to learn SQL myself — it's funny that I'm building a platform where people can explore data using SQL and I didn't even know how to write a query when I started. 😄 If you're here, you're on the same journey. Don't be afraid to break things and ask questions — that's how you learn."

Querii is a fork of AttendanceProcessor — built with Python, SQLite, and pywebview. Zero cloud, zero tracking, runs entirely on your machine.

How to use

  1. Import — Drop a file or Browse. Preview detects column types. Hit Import.
  2. File List — Click "📁 Files" to manage tables, select multiple for JOIN mode.
  3. Visual Filter — Add conditions and groups. Groups create (A AND B) OR (C AND D) style SQL automatically.
  4. SQL Editor — Auto-filled from the filter. Edit freely, Ctrl+Enter to run.
  5. 💡 Explain — Click "Explain" for a plain-English description of any query.
  6. 📝 Templates — Ready-made SQL patterns to get started fast.
  7. Schema stats — Click any column in the Schema panel to see stats (min, max, distinct, nulls).
  8. Export — Export any result to CSV or PDF.
