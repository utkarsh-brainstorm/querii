Platform Capabilities

1. File Import & Multi-Format Ingestion

Drag and drop or browse CSV, TSV, Excel (.xlsx, .xls), JSON, and SQLite files. Instant schema detection with automated type inference. Multi-table datasets are loaded as independent SQL tables within the local database.

2. Visual Filter & JOIN Builder

Construct complex queries visually without typing SQL. Add grouped conditions generating (A AND B) OR (C AND D) boolean trees. Enable multi-table mode to define INNER/LEFT joins with custom ON conditions and aggregations.

3. Full SQL Workspace (DML & DDL Enabled)

The SQL editor supports complete database interaction: SELECT, WITH, INSERT, UPDATE, DELETE, ALTER TABLE (ADD COLUMN, DROP COLUMN, RENAME COLUMN), and CREATE TABLE. Transactions commit automatically with live schema reloading. Standalone DROP TABLE commands are reserved for Developer Mode (Settings → Advanced) for data safety.

4. 💡 Plain-English SQL Explainer

Click "Explain" to parse your query AST into plain human terms. Breaks down selected columns, table sources, join conditions, where predicates, groupings, and orderings.

5. Global In-Memory Search (Ctrl+F)

Perform instant browser-style search across all displayed table cells. Matches are highlighted dynamically with <mark> tags, and pressing Enter automatically cycles through occurrences.

6. Ultra Dev Mode & Executive PDF Studio

An interactive desktop studio for publishing audit-grade documents. Features authentic physical page sheet geometry (A4, A3, Letter in Portrait/Landscape), interactive mouse-drag column resizing, 5 complete editable CSS presets, Libron corporate typography, content scaling (100%, 80%, 60%, 120%), dense repeating watermarks, and isolated preview canvas zoom (Ctrl +/-).
